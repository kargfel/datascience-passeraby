# 🚶‍♂️ Explorative Datenanalyse: Passantenfrequenzen in Würzburg

![License](https://img.shields.io/badge/License-MIT-yellow)

## 📋 Über das Projekt

Dieses Repository beinhaltet eine explorative Datenanalyse (EDA) der Passantenströme in der Würzburger Innenstadt. Ziel des Projekts ist es, Muster in der Besucherdichte zu erkennen, saisonale Trends zu identifizieren und Hypothesen über Einflussfaktoren zu überprüfen.

Die Analyse hilft dabei zu verstehen, wie sich die Stadt bewegt – von den ruhigen Morgenstunden bis zum Trubel während des Weihnachtsmarktes.

### 🎯 Ziele der Analyse
* **Zeitliche Muster:** Identifizierung von Spitzenzeiten (Stündlich, Wochentage, Monatlich).
* **Standortvergleich:** Vergleich zentraler Messstellen (z.B. Domstraße vs. Schönbornstraße).
* **Event-Einfluss:** Analyse der Auswirkungen lokaler Events und Feiertage.
* **Wetter-Einfluss:** Untersuchung der Korrelation zwischen Passantenzahlen und Wetterbedingungen (falls Wetterdaten integriert).

## 💾 Datenbasis

Die Datengrundlage bilden Frequenzzählungen von Passanten.

* **Quelle:** [Würzburg Open Data Portal]
* **Zeitraum:** [01.01.2024 bis 31.12.2024]
* **Granularität:** [Stundenwerte über 3 Messtellen]
* **Dateiformat:** `.csv`

> **Hinweis:** Die Rohdaten liegen in `passanten_wuerzburg.csv`.
